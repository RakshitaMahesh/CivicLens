# CivicLens — Smart City Issue Reporting & Monitoring Dashboard

An interactive web-based prototype designed to demonstrate how citizens can report civic issues and how city teams can monitor reported problems through a centralized dashboard.

## ✨ Key Features

- **Dashboard:** Overview of civic issue monitoring.
- **Issue Reporting:** Interface for submitting civic issues.
- **Live Reports Feed:** Displays reported issue information.
- **Smart Map:** Map-based visualization of issue locations.
- **Smart Analytics:** Charts for visualizing issue-related data.
- **Responsive Interface:** Dashboard layout designed for convenient navigation.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js — data visualization
- Leaflet.js — interactive maps
- OpenStreetMap — map tiles
- GitHub Pages — website hosting

## 🚀 Run the Project Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/RakshitaMahesh/CivicLens.git
   ```

2. Open the downloaded project folder.
3. Open `index.html` in your browser.
4. Ensure you have an internet connection for externally hosted map tiles and libraries.

Alternatively, download the project using GitHub's **Code → Download ZIP** option.

## 🎯 Project Objective

CivicLens demonstrates a centralized interface for civic issue reporting, location visualization, and analytics. It aims to illustrate how web technologies can support smart-city monitoring workflows.
